# VerseCatch

VerseCatch captura una imagen con la cámara, ejecuta OCR con ML Kit y extrae citas bíblicas detectadas en el texto.

## OCR modes

- **Standard mode**: recorte central ligero (90%) para preservar más contenido.
- **Document mode**: recorte central más agresivo (80%) para reducir ruido de fondo cuando hay página inclinada o mucho borde.

Activa **Document mode** desde el switch en la pantalla principal antes de analizar la imagen.
